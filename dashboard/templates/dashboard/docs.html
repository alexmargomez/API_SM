Documentación de API

Referencia de endpoints para consulta y extracción de datos

Información General

Todos los endpoints de búsqueda devuelven los resultados en formato JSON y no requieren autenticación (CORS habilitado).

Ruta Base: /api/

GET /api/cie10

Busca en el catálogo de diagnósticos CIE-10 por código o descripción.

Parámetros (QueryString)
ParámetroTipoDescripción
q String (Opcional) Término de búsqueda. Coincide con código o descripción.
limit Integer (Opcional) Número máximo de resultados. (Por defecto: 100)
Ejemplo de Respuesta
[
  {
    "codigo": "A000",
    "descripcion": "COLERA DEBIDO A VIBRIO CHOLERAE O1 BIOTIPO CHOLERAE",
    "version": "2024",
    "version_fecha": "2024-01-01"
  }
]
GET /api/cups

Parámetros (QueryString)
ParámetroTipoDescripción
q String (Opcional) Término de búsqueda. Coincide con código o descripción.
limit Integer (Opcional) Número máximo de resultados. (Por defecto: 100)

GET /api/entidades

Busca en el catálogo de Entidades / EPS / AFP por NIT, nombre o código.

Parámetros (QueryString)
ParámetroTipoDescripción
q String (Opcional) Término de búsqueda. Coincide con NIT, código, nombre o régimen.
limit Integer (Opcional) Número máximo de resultados. (Por defecto: 100)
Ejemplo de Respuesta
[
  {
    "ent_id": "EPS037",
    "ent_nombre": "NUEVA EPS S.A.",
    "nit": "900156264",
    "tps_rgm_nombre": "CONTRIBUTIVO"
  }
]
